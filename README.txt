UniHub 100% Front-End
======================
التقنيات:
HTML5 + CSS3 + JavaScript ES6
بدون مكتبات خارجية وبدون Backend.

التشغيل:
1) فك الضغط.
2) افتح index.html في المتصفح.
3) اضغط دخول المنصة.
4) أدخل أي اسم ورقم جامعي وتخصص.
5) استخدم القائمة الجانبية.

الخدمات:
- لوحة التحكم
- المواد CRUD
- الواجبات CRUD + بحث + إكمال
- الجدول الأسبوعي
- الحضور والنسب
- الاختبارات
- حساب GPA
- الملاحظات
- مكتبة الملفات المحلية
- الأهداف
- الإعلانات
- Pomodoro
- الإحصائيات
- التقويم
- الملف الشخصي
- الوضع الليلي
- بحث عام
- LocalStorage
- Responsive

مهم:
هذا إصدار Front-End كامل للتعلم/العرض والتسليم الجامعي. تسجيل الدخول محلي على الجهاز وليس نظام حسابات حقيقياً. لا توجد قاعدة بيانات أو حسابات متعددة أو مزامنة بين الأجهزة؛ هذه تحتاج Backend + Database + Authentication.
